# Sample data for testing PET

`sample-data.json` is a small, entirely fake dataset you can use to try out PET before entering your own real expenses.

**What's in it:**
- 12 categories with subcategories (Food, Grocery, Personal, Apparel, Household, Recharge, Books/Stationery, Fancy Store, Health, Transportation, Gift, Other)
- 5 account types with sub-accounts (Credit Card ×2, Debit Card, UPI ×2, Bank Transfer, Cash) — including the "requires payment/settlement" setup on Credit Card
- 20 sample transactions across 8 days (Aug 12–19, 2026), spanning two calendar weeks, with a mix of paid and pending credit card entries

None of it is real — all merchant names, amounts, and notes are made up for demonstration purposes only.

## How to load it

1. Open PET.
2. Go to **Settings → Data**.
3. If you have real data already, back it up first (**Backup everything**), so you can restore it afterward.
4. Under **Complete backup**, tap **Restore everything**, and select `sample-data.json`.
5. When you're done exploring, restore your own backup the same way (or **Reset all data** to start fresh).
